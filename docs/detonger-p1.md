# 德佟印立方 P1：Android 蓝牙打印

## 使用

1. 在 Android 系统蓝牙中配对 P1，退出微打等占用打印机连接的应用。
2. 在标签编辑器的「纸张」中设置宽、高和旋转。有效设置自动保存在本机，无需先打印。
   在「自定义尺寸」中填写名称并「保存并使用」，可保存最多 12 个预设，包含尺寸、纸型、旋转和两个偏移；相同名称可更新。
   预设不保存元件名称、SKU 或二维码内容；更换元件后仍按当前元件生成标签。
3. 在打印确认页选择已配对的打印机，再选择「德佟 P1」协议；在纸张页选择间隙纸或连续纸。应用会记住该设备的协议。
4. 创建一张标签的队列，检查实物和二维码后再进行批量打印。

编辑画布宽高均支持 10–300 mm；它并不代表所有打印机都能打印该尺寸。
P1 打印范围为宽 10–48 mm、高 10–300 mm，高度上限是本应用限制。
宽度是横跨打印头的方向，高度是走纸方向；90°/270°旋转内容不会扩大打印头。
超出所选机型范围时仍可编辑/导出，但不能创建该机型的打印队列，页面会显示具体范围。
已有队列保留原来的纸张、机型和设计快照，修改预设不会改变排队任务。

批量更换库存标签：在「库存」中按名称、SKU、分类或仓位筛选，点「选择」，勾选多种元件
或「全选筛选结果」，然后点「打印所选标签」。进入确认页后统一选择纸张预设，检查预览并创建队列。
默认每种元件一张，不按库存数量重复打印；可在元件选择面板修改份数。每批最多 500 张。

## 实现与来源

- [德佟官方产品与 SDK 入口](https://www.detonger.com/sdk/list)：P1 规格为蓝牙/USB、48 mm 打印宽度。
- 使用官方 `LPAPI-2026-10-21-R.jar`；原始来源和 SHA-256 见 [SDK 说明](../android-client/app/libs/README.md)。
- Android 使用已配对设备的 Classic Bluetooth/SPP；本次未增加电脑 USB 或 BLE 搜索流程。
- 复用现有 203 dpi 位图。连接后读取 SDK 设备信息，核对 P1 型号、203 dpi 和可打印宽度；不自动缩放二维码。
- 每次只提交一张，旋转和偏移在共享渲染器中应用，传入 SDK 的方向固定为 0°，避免二次旋转。
- `PrintProgress.Success` 表示 SDK 完成该任务，允许队列继续；不是相机或人工检查实物的结果。
  提交后的失败、断开或超时按「待核对」处理，避免自动重复出纸。离开页面或停止任务会释放连接。

## 验证

自动回归覆盖尺寸边界、预设持久化、旋转恢复、队列快照，以及 P1 的连接失败、机型不符、成功、超时和取消。
最初基于 `5892e4a` 的版本有 72 项相关测试通过；与 `5fee003`（0.7.9-dev.20）合并后重新验证打印、预设迁移及批量导入。
`assembleDebug` 成功；`lintDebug` 仍有上游既存的翻译、CameraX opt-in 和 Compose 检查问题。
另有 `LabelPrintQueueStoreTest.loadPersistsRecoveryAndPreservesCompletedStates` 在 Windows Robolectric 环境失败，
已在未修改的 `5892e4a` 上复现；本次未修改该存储实现。
2026-11-12：Android 16 手机通过 Classic Bluetooth/SPP 连接 P1，设备报告 203 dpi、384 点打印宽度。
40 × 30 mm 间隙纸的文字及二维码测试已实际出纸，SDK 返回 `Success`，队列进入已发送状态。
最初的左对齐与居中对齐测试曾出现左侧裁切，随后建议以 X = +2 mm、Y = 0 mm 作为用户预设的起始补偿值；不是所有 P1 的固定参数。
2026-11-12 后续用户反馈：已自行验证位置校准和连续出纸，均正常。此结论来自用户实机反馈，未记录最终偏移、连续张数或具体测试固件。
连续出纸指连续打印多张标签，不据此推定连续纸耗材也已验证；连续纸、其他固件仍未确认。批量选择、内容隔离与队列行为另有自动回归覆盖。

## 与 0.7.9-dev.20 合并

- 保留上游的「打印确认 → 编辑」流程、纸张选择页、按设备记忆协议和校准，以及 M1 / 通用 CPCL 的发送流程。
- P1 使用独立 SDK 分支，不会被当作通用 CPCL；已有 M1、HM-A300E 和通用 CPCL 队列仍按原协议恢复。
- 扩展上游纸张预设格式以保存旋转、X/Y 偏移；旧版仅有尺寸和纸型的预设仍可读取。
- 之前 P1 测试版的命名预设和最后使用参数会迁移一次；删除已迁移的预设后不会再次从旧设置恢复。
- 纸张预设只影响新标签。选择预设时使用当前元件的名称、SKU 和二维码，不修改已有队列快照。
- 未选择新纸张时恢复最后的有效参数；切换打印机仍使用上游按设备保存的校准，主动应用纸张预设会采用该预设的偏移。
- 标签画布继续允许 10–300 mm，打印确认阶段单独检查设备物理范围，P1 最大宽度保持 48 mm。
- 同一提交包含[批量 C 编码 / XLSX 导入](batch-code-import.md)，复用原有资料解析和确认入库链路。
