# 德佟印立方 P1：Android 蓝牙打印

## 使用

1. 在 Android 系统蓝牙中配对 P1，退出微打等占用打印机连接的应用。
2. 在标签编辑器的「纸张」中设置宽、高和旋转。有效设置自动保存在本机，无需先打印。
   「我的纸张预设」可保存最多 12 个名称，包含尺寸、旋转和两个偏移；相同名称可更新。
   预设不保存元件名称、SKU 或二维码内容；更换元件后仍按当前元件生成标签。
3. 进入「打印」，选择「德佟 P1」，选择间隙纸或连续纸，刷新并选择已配对的打印机。
4. 创建一张标签的队列，检查实物和二维码后再进行批量打印。

编辑画布宽高均支持 10–300 mm；它并不代表所有打印机都能打印该尺寸。
P1 打印范围为宽 10–48 mm、高 10–300 mm，高度上限是本应用限制。
宽度是横跨打印头的方向，高度是走纸方向；90°/270°旋转内容不会扩大打印头。
超出所选机型范围时仍可编辑/导出，但不能创建该机型的打印队列，页面会显示具体范围。
已有队列保留原来的纸张、机型和设计快照，修改预设不会改变排队任务。

批量更换库存标签：在「库存」中按名称、SKU、分类或仓位筛选，点「选择」，勾选多种元件
或「全选筛选结果」，然后点「打印所选标签」。进入编辑器后统一选择纸张预设，检查预览并创建队列。
默认每种元件一张，不按库存数量重复打印；可在元件选择面板修改份数。每批最多 500 张。

## 实现与来源

- [德佟官方产品与 SDK 入口](https://www.detonger.com/sdk/list)：P1 规格为蓝牙/USB、48 mm 打印宽度。
- 使用官方 `LPAPI-2026-10-21-R.jar`；原始来源和 SHA-256 见 [SDK 说明](../android-client/app/libs/README.md)。
- Android 使用已配对设备的 Classic Bluetooth/SPP；本次未增加电脑 USB 或 BLE 搜索流程。
- 复用现有 203 dpi 位图。连接后读取 SDK 设备信息，核对 P1 型号、203 dpi 和可打印宽度；不自动缩放二维码。
- 每次只提交一张，旋转和偏移在共享渲染器中应用，传入 SDK 的方向固定为 0°，避免二次旋转。
- `PrintProgress.Success` 表示 SDK 完成该任务，允许队列继续；不是相机或人工检查实物的结果。
  提交后的失败、断开或超时按「待核对」处理，避免自动重复出纸。离开页面或停止任务会释放连接。
