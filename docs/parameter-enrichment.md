# Web 库存资料检查

## 扫描和应用

进入「库存 → 库存工具 → 库存资料检查」，可以扫描当前账户的全部有效元件，
包括零库存元件。中文界面查询国内嘉立创 EDA，英文界面查询国际 EasyEDA。

1. 先把手机和 Windows 的待同步修改同步到服务端，避免仍有离线编辑。
2. 选择「只补缺失」或「复查已有参数」，点击「扫描当前账户库存」。扫描只生成预览。
   服务端优先查询完整 C 料号。没有 C 料号时，只有厂商型号和品牌能唯一匹配，
   并且与已有可比封装、电气参数相符，才会给出候选。
3. 比较当前值和拟更新值。可以逐项勾选，也可以点击「全选可更新资料」，一次勾选本次扫描所有页面的可更新字段，包括已有值差异和商城参考价。按厂商型号匹配的候选须单独确认，之后才可纳入。确认前仍可取消任意字段。
4. 点击「应用所选」并确认。未使用跨页全选时，按钮为「应用本页所选」。跨页更新会自动分批提交，参数逐项合并。
   Web 库存操作关闭时仍可扫描，启用后才能应用。
5. 手机和 Windows 再次同步，获取新资料。

应用只修改已选字段，保留原名称、SKU、图片、自由备注、数量、最低库存、库位、
分配、实际成本和出入库流水。

参考价显示币种、适用采购数量档、来源和查询时间。国内阶梯价取最小有效数量档
对应的单价，不把最大批量的低价当作单件购买价。查询时间不是供应商报价更新时间，
不代表实际采购成本，下单价格以商城为准。未提供价格时不会删除已保存的参考价。

## 失败、冲突和恢复

- 无可查料号、无精确匹配、目录缺资料、请求失败及限流分别显示。遇到限流时，本轮后续请求暂停，可稍后重试相关条目。
- 取消在当前查询结束后生效；失败和未处理项可重试。
- 预览仅临时保存在服务器中，服务重启后需重新分析；重新分析仍然不修改库存。
- 应用时逐项检查元件版本，期间被其他设备修改的项目报冲突，不覆盖新修改。
- 网络中断时，可以点击「重试未完成项」。已确认结果的条目不会重新提交，结果未确认的条目会复用原请求 ID。
- 「清除预览」仅清除本次任务结果。旧的「补全旧元件参数」面向完全没有参数的旧元件，
  全库缺项与差异请使用「库存资料检查」。

## 版本要求

API 与 Web 管理台应使用同一版本。找不到「库存资料检查」或「全选可更新资料」时，
先核对当前部署版本与更新日志，再按 [Docker 渠道教程](docker-channels.md)更新。
