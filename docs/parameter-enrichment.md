# 旧库存中文资料与参数更新

## 从国内嘉立创 EDA 批量更新

Web 库存页提供“国内资料批量更新”。它按当前账户的完整 C 料号查询国内
嘉立创 EDA，不需要 Cookie、商城登录或 OpenAPI 密钥，也不查询国际站备用资料。
适用于过去导入了英文分类、缺少参数或没有参考价格的库存。

1. 先把手机和 Windows 的待同步修改同步到服务端，避免仍有离线编辑。
2. 使用同一账户登录管理台，打开“库存 → 国内资料批量更新”。
3. 点击“分析当前账户全部库存”。分析不修改元件，也不新增入出库流水。
   页面显示进度，无有效 C 料号的手工元件会跳过；查询失败可单独重试。
4. 分页核对当前值和拟更新值。可分别勾选分类、封装、明确参数组和参考价。
   **参数组会按预览整体替换**；若要保留原参数组，请取消该项。
5. 点击“应用本页已选字段”，核对确认范围后应用。每页最多 50 个元件，
   大库存可逐页复核，已应用项不会增加库存数量。
6. 手机和 Windows 再次同步，获取服务端更新的分类、封装、参数和参考价。

应用只改变勾选的资料组，保留已有名称、SKU、图片、自由备注、数量、最低库存、
库位、分配和流水。不会批量改名、自动扣料或从型号编码猜测电气参数。
Web 库存操作关闭时仍可分析预览；实际应用需先在服务端启用 Web 库存操作。

参考价显示币种、适用采购数量档、来源和查询时间。国内阶梯价取最小有效数量档
对应的单价，不把最大批量的低价当作单件购买价。查询时间不是供应商报价更新时间，
不代表实际采购成本，下单价格以商城为准。未提供价格时不会删除已保存的参考价。

## 失败、冲突和恢复

- 国内公开入口仍可能限流、验证或调整，失败时明确列出，不自动切换国际站。
- 取消在当前查询结束后生效；失败和未处理项可重试。
- 预览仅临时保存在服务器中，服务重启后需重新分析；重新分析仍然不修改库存。
- 应用时逐项检查元件版本，期间被其他设备修改的项目报冲突，不覆盖新修改。
- 网络中断导致结果不确定时，界面复用原请求 ID 重试，避免重复应用。
- “清除预览”只清除任务结果，不删除元件。旧的“补全旧元件参数”入口仍保留兼容，
  需要中文分类、封装和参考价时请使用新的批量更新工具。

## 开发版部署

此功能可随 dev 源码、Web 附件或对应开发镜像使用。dev 不替换 Docker Hub 的 latest /
web-latest；只拉旧的正式镜像不会得到新接口。API 与 Web 必须配套更新。
从 dev.5 起开发镜像使用 dev/web-dev，切换步骤见[Docker 渠道教程](docker-channels.md)，
需以独立 Docker 发布成功且配套标签可拉取为准。

源码 Compose 部署可在对应 dev 标签目录中，保留**原 Compose 项目名**、原 .env
及完整 /data 挂载，先备份再构建：

    docker compose --project-name <原项目名> -f docker-compose.yml up -d --build

这条命令用于源码构建，不适用于直接拉镜像的 docker-compose.hub.yml。
群晖等自定义部署也应沿用原端口和数据映射，避免误连新建的空数据库。
