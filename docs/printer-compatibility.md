# 标签打印机兼容性

| 机型或平台 | 使用方式 | 实测范围 |
| --- | --- | --- |
| 汉印 M1 · Android | 系统蓝牙配对后，从标签编辑器选择 M1。支持元件标签、自由标签和逐张队列。 | 一台 M1 使用 40 × 60 mm 间隙纸完成单张、连续两张和二维码回扫。其它纸张、固件与长队列需分别核对。[M1 使用指南](m1-printing-feature-matrix.md) |
| 汉印 HM-A300E · Android | 使用带汉印 CPCL SDK 的构建。选择与设备一致的间隙纸或连续纸，逐张核对实物。 | 小米 9 与同一台 HM-A300E 在 dev.12 SDK 测试包上完成同队列两张 40 × 60 mm 间隙标签。连续纸和其它固件尚无对应实测。[SDK 与型号指南](hm-a300e.md) |
| Windows 或其它打印机 | 导出标签文件后，用设备支持的打印软件打印。 | 导出与打印机连接、纸型校准分别处理。[标签与 Excel 导出](storage-and-backup.md) |
| 德佟印立方 P1 · Android | 系统蓝牙配对后选择「德佟 P1」，内置官方 LPAPI SDK，支持间隙纸/连续纸选项。 | 打印宽度上限 48 mm；验证边界见 [P1 适配说明](detonger-p1.md)。 |

Android 可从「元件详情 → 生成标签」或「库存 → 更多 → 标签工具」进入同一编辑器。
选择实际纸张并检查预览后再创建队列。标签位置按每台设备单独校准。

遇到缺纸、开盖、连接失败或待核对状态时，先确认当前标签是否已经出纸，再选择重打、标记完成或跳过。打印报告用于定位连接与发送过程，实物和回扫用于确认结果。

协议与早期实验详见 [M1 协议分析](m1-apk-analysis.md) 和 [历史验证](history/verification.md)。
