# 0.7.8 正式版

本版汇总 0.7.8-dev.1–dev.24 的功能与修复，并增加 Android、Windows 启动检查更新。此前已有的账户管理、审计及标签模板不作为本版新增。发布入口：[v0.7.8](https://github.com/Rafael-Ikaros/Component_Manager/releases/tag/v0.7.8)；实际附件与镜像状态以发布流水线为准。

## BOM、配套件与库位

- Android、Windows BOM 改为选文件及套数、匹配库存、确认出库三步；自动识别嘉立创 EDA 常用列，列映射可展开查看样例。无料号测试点等行可人工匹配或跳过、恢复，重复需求聚合并检查缺料。
- BOM 预设保留来源行、套数、人工选择及跳过项，再次使用重新读取当前库存。两端同账户同步预设及删除，采用整个预设 LWW，不提供人工字段合并。旧文件迁移前备份；Excel 库存备份不包含预设 JSON，应单独保护。
- 两端配套件支持从库存选料或带入预设，调整数量并复核库位扣减后一次出库。打开、保存或同步预设不扣库存；草稿不跨设备、不预留库存。
- Android 保留旋转和暂存 BOM 上下文，恢复时重新匹配现库存。严格 R/C/L 推荐仅 Android 提供，要求明确同电气参数、同封装及同类型，必须人工采纳；Windows 尚无此推荐。
- Android 本机采购在途及到货提醒、缺料 CSV 导出后批量标记，不自动扣料，不跨设备或纳入 Excel 备份。
- 编辑主库位会集中全部库存，部分转移仍用转移入口。界面显示库位名称，内部稳定 ID 保持；隐藏无库存的旧分配，保留历史。Windows 修复删除元件后空库位删除和历史同步重新激活库位。
- 两端标签 Excel 支持全部或多选库位，指定库位按元件与库位分行。Android 支持库位标签与扫码筛选、多库位分配筛选。

## 导入、照片与同步

- Android、Windows 支持立创订单 BIFF `.xls` 入库复核；Android 跳过表尾合并说明及配送费汇总，本机按订单号与 SKU 防重。Windows 修改料号后重新核对商品资料，保留退款、缺订单及冲突警告，不把查询视为确认。
- Android 分类学习跨相同官方分类路径复用，保留用户字段；手动无 SKU 元件可生成 CV- 编号。记录扫码先选出入库，包装数量不自动作为扣减数量；数量快捷加减和库存约束保留。
- Android 支持拍照、图库选图及备份图片。Android、Windows 同账户原图互通，Web 登录后查看；照片失败单独提示，库存无增量也能重试。清下载缓存保留用户原图和关联。
- 库存、预设、照片分别持久化阶段结果与成功时间；失败、取消及进程中断保留已完成结果，重新通过同步入口继续。同期本地修改留待下一轮，不提供后台自动恢复。
- Web 新增“从订单更新资料”（#25）：精确匹配已有 C 料号、预览并选择中文分类、封装和明确参数。保留名称、图片、自由备注、数量、库位和流水；不新增元件。支持逐项版本检查与幂等重试。需 API/Web 配套升级及启用 Web 库存操作。
- 修复同步空库位误存为 null 文字导致备份失败；同步时收敛无效引用，保留真实同名库位、原库存和流水。

## 客户端交互与更新

- 两端核心模块分离，保留数据库、离线方式与既有同步边界。Windows 保存失败保留输入，保存成功而刷新失败明确告知；修复筛选下追加已有 SKU、筛选及选择保持。Windows 支持 Markdown 更新日志。
- Android 修复记录扫码弹窗崩溃、编辑旋转草稿差异，保留系统状态恢复及取消图片清理；导入新建库位后刷新共享状态。
- Android 设置、表单、BOM、标签尺寸及配套件改善横屏键盘可达性。平板首阶段提供紧凑库存列表/详情和设置分组，保留搜索、选择、草稿与返回上下文。后续平板 BOM、标签、配套件工作区延期。
- 修复 GitHub 改名后的更新检测地址。Android 可在应用内下载 APK、查看进度、取消重试并打开系统安装；Windows 使用既有 ZIP 下载入口。两端每次启动按当前 stable/dev 通道检查一次，仅新版弹窗，最新或失败静默；手动检查保留。

## 升级与验证边界

稳定发布会更新 Docker stable 标签（latest/web-latest），不同于前述 dev 发布。API 与 Web 配套升级，升级前备份整个 /data，包含账户数据库旁的 .photos 目录；仅备份 SQLite 无法恢复原图。客户端覆盖安装前保留本地备份，旧地址检测失败的客户端需手动覆盖安装一次，无需卸载清数据。

历史定向测试、CI 与设备证据见 [CHANGELOG](../CHANGELOG.md)、[跨设备记录](../personal-cross-device-todo.md)及[当前工作记录](../current-work.md)。dev18 已验证预设往返与配套件；dev19 验证 Windows/手机/Web 原图字节一致；dev20 验证中断、取消与重试；#25 在 dev21 实现，dev22 完成手机同步及备份字段核对；dev23/24 验证 Android 横竖屏键盘与平板首阶段，备份核对保持原资料。这些是已记录的具体路径，不代表所有功能、平台或实体打印全部验收。
