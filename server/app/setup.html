管理员登录

使用当前的管理员 API Token。普通用户可在 Web 管理台使用各自的账户密钥登录。

在哪里查找管理员令牌？

通过此页面保存的令牌位于服务端数据目录的配置文件中。容器默认路径为 /data/config.json，字段名为 API_TOKEN。

如果部署时显式设置了非空的 API_TOKEN 环境变量，请使用该值。可以在部署配置或 API 容器的环境变量中查看。其他用户请联系管理员。

管理员凭据

生成令牌，或填写至少 16 个可见 ASCII 字符。请把令牌保存到密码管理器，以便登录服务端配置和 Web 管理台。

此项为只读。要更改令牌，请更新 API_TOKEN 环境变量并重新创建容器。

Web 管理台（可选）

Web 管理台独立部署。只使用 Android 或 Windows 客户端时，可跳过此处。

填写浏览器打开管理台的完整 URL，可包含反向代理子路径。保存后可从此页打开管理台。

此项为只读，由 ADMIN_WEB_URL 环境变量控制。

跨域访问时，每行填写一个管理台来源，包含协议、主机和端口（如有）。只填到主机或端口，例如 https://vault.example.com。

此项为只读，由 ADMIN_WEB_ORIGINS 环境变量控制。

此项为只读，由 WEB_INVENTORY_ENABLED 环境变量控制。
